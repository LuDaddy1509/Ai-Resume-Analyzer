# Tech Job Market Trends 2024-2025

## Top In-Demand Skills (Q4 2024 - Q2 2025)

### AI/ML & Generative AI
- **LLM Application Development**: RAG, Fine-tuning, Prompt Engineering, Agentic workflows
- **MLOps**: MLflow, Kubeflow, Vertex AI, SageMaker, Model monitoring & drift detection
- **Vector Databases**: Pinecone, Weaviate, Qdrant, Milvus, ChromaDB
- **AI Frameworks**: LangChain, LlamaIndex, AutoGen, CrewAI, Semantic Kernel

### Cloud & Infrastructure
- **Multi-cloud**: AWS + GCP/Azure combos
- **Serverless**: Lambda, Cloud Functions, Cloud Run
- **Kubernetes**: EKS, GKE, AKS, Helm, Operators, Service Mesh (Istio/Linkerd)
- **Infrastructure as Code**: Terraform, Pulumi, Crossplane
- **Platform Engineering**: Internal Developer Platforms (Backstage, Port)

### Data Engineering
- **Modern Data Stack**: dbt, Snowflake/BigQuery/Redshift, Airflow, Fivetran
- **Streaming**: Kafka, Flink, RisingWave, Redpanda
- **Data Quality**: Great Expectations, Monte Carlo, Soda
- **Lakehouse**: Delta Lake, Iceberg, Hudi

### Backend & Systems
- **Languages**: Go, Rust, TypeScript (Node.js/Bun/Deno), Python
- **Architecture**: Event-driven, CQRS, Event Sourcing, Distributed Systems
- **Databases**: PostgreSQL (advanced), ClickHouse, Redis, MongoDB, CockroachDB
- **API**: gRPC, GraphQL, tRPC, REST best practices

### Security & Compliance
- **DevSecOps**: SAST/DAST/SCA, SBOM, Supply chain security (SLSA, Sigstore)
- **Cloud Security**: CSPM, CWPP, CIEM
- **Zero Trust**: BeyondCorp, SPIFFE/SPIRE

## Hiring Trends
1. **AI-First Roles**: AI Engineer, ML Engineer, Prompt Engineer, RAG Specialist
2. **Full-Stack + AI**: Full-stack developers có khả năng integrate AI features
3. **Platform/DevEx**: Platform Engineer, DevEx Engineer, SRE
4. **Data + AI**: Data Engineer với ML skills, Analytics Engineer

## Salary Signals (US Market, Senior Level)
- AI/ML Engineer: $180-280k
- Platform Engineer: $160-240k
- Senior Backend (Go/Rust): $170-250k
- Staff/Principal Engineer: $250-400k+

## Red Flags trong JD
- "Rockstar/Ninja/Guru" - thường chỉ junior role được overhype
- "Wear many hats" - thiếu định hướng, scope creep
- Yêu cầu 10+ năm kinh nghiệm với công nghệ mới 2 năm (React 2013, Kubernetes 2014)
- Không mention tech stack cụ thể
