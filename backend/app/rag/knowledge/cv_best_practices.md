# Best Practices cho CV IT / Tech

## Cấu trúc CV tối ưu cho ATS
- **Header**: Họ tên, Email, Phone, LinkedIn, GitHub/Portfolio
- **Summary/Objective**: 2-3 dòng, tập trung vào value proposition, keywords từ JD
- **Technical Skills**: Phân nhóm (Languages, Frameworks, Databases, Cloud, Tools)
- **Experience**: Reverse chronological, dùng STAR method cho bullet points
- **Projects**: 2-3 projects nổi bật, có link GitHub/demo, mô tả tech stack & impact
- **Education**: Degree, major, GPA (nếu > 3.5), relevant coursework
- **Certifications**: AWS, Azure, GCP, CKAD, PMP, etc.

## Bullet Points theo STAR Method
- **S**ituation: Bối cảnh dự án/vấn đề
- **T**ask: Nhiệm vụ bạn đảm nhận
- **A**ction: Hành động cụ thể bạn thực hiện (dùng động từ mạnh: Developed, Led, Optimized, Architected...)
- **R**esult: Kết quả định lượng (tăng 30% performance, giảm 40% latency, tiết kiệm $50k/năm)

## Ví dụ tốt vs kém
❌ Kém: "Làm backend cho hệ thống e-commerce"
✅ Tốt: "Architected và developed microservices backend cho e-commerce platform 1M+ users/day sử dụng Go, gRPC, PostgreSQL, Redis. Optimized API latency từ 200ms xuống 45ms (giảm 77%) bằng cách implement caching layer và database indexing strategy."

## Kỹ năng cần làm nổi bật (2024-2025)
**Programming**: Python, Go, TypeScript, Rust, Java, C++
**AI/ML**: PyTorch, TensorFlow, LangChain, RAG, LLM Fine-tuning, MLOps
**Cloud/DevOps**: AWS (ECS/EKS/Lambda), Terraform, Kubernetes, CI/CD (GitHub Actions, GitLab CI), Observability (Prometheus, Grafana, Datadog)
**Data**: PostgreSQL, ClickHouse, Kafka, Spark, Airflow, dbt
**Architecture**: System Design, Microservices, Event-driven, DDD, Hexagonal Architecture

## ATS Optimization
- File format: PDF (text-based) hoặc DOCX - tránh PDF scan/image
- Font: Arial, Calibri, Roboto, Inter - size 10-12pt
- Không dùng: Tables, text boxes, headers/footers phức tạp, graphics, columns
- Keywords: Mirror chính xác từ khóa trong JD (React ≠ React.js, AWS ≠ Amazon Web Services)
- Section headings tiêu chuẩn: Experience, Education, Skills, Projects, Certifications
