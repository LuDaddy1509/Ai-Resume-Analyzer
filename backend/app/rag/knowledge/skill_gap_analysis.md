# Skill Gap Analysis & Career Development Framework

## Competency Matrix by Level

### Software Engineer Levels
| Competency | Junior (L1-L2) | Mid (L3) | Senior (L4-L5) | Staff/Principal (L6+) |
|------------|----------------|----------|----------------|----------------------|
| **Coding** | Clean code, basics | Design patterns, testing | Architecture decisions, refactoring | Technical strategy, cross-team |
| **System Design** | Understand components | Design services | Design distributed systems | Platform architecture |
| **Debugging** | Fix bugs | Root cause analysis | Preventive observability | System reliability |
| **Collaboration** | Team player | Cross-functional | Influencing without authority | Org-wide initiatives |
| **Mentorship** | Learning | Onboarding juniors | Growing seniors | Developing leaders |

### Skill Categories & Assessment

#### 1. Technical Depth (Hard Skills)
**Programming Languages**
- Expert (can teach): 1-2 languages
- Proficient (daily use): 2-3 languages
- Familiar (can ramp up): 3+ languages

**Frameworks & Libraries**
- Deep: 2-3 core frameworks
- Working knowledge: 5-10 frameworks

**Infrastructure & Tools**
- CI/CD: GitHub Actions, GitLab CI, Jenkins, ArgoCD
- Containerization: Docker, Kubernetes (CKA level for platform roles)
- Cloud: 1 major cloud (AWS/GCP/Azure) certified preferred
- Observability: Prometheus/Grafana, Datadog, ELK, OpenTelemetry

#### 2. Domain Knowledge
- **Fintech**: Payments, ledgers, compliance (PCI-DSS, SOX), transaction integrity
- **E-commerce**: Inventory, cart, checkout, recommendations, search
- **SaaS/B2B**: Multi-tenancy, billing, integrations, API design
- **Healthcare**: HIPAA, FHIR, HL7, audit trails
- **AI/ML**: MLOps, feature stores, model serving, evaluation

#### 3. Soft Skills (Power Skills)
- **Communication**: Technical writing, presentations, RFCs, documentation
- **Leadership**: Delegation, conflict resolution, psychological safety
- **Product Sense**: User empathy, prioritization, metrics definition
- **Strategic Thinking**: Roadmap planning, tech debt management, ROI analysis

## Gap Analysis Process

### Step 1: Target Role Definition
```
Current: Senior Backend Engineer (Python, Django, PostgreSQL, AWS)
Target:  Staff Engineer (Platform) at Series B startup
Gap:     Kubernetes, Terraform, Go/Rust, System Design at scale, Cross-team leadership
```

### Step 2: Skill Inventory
Rate each skill 1-5:
- 1: Never heard
- 2: Read about it
- 3: Used in project
- 4: Production experience
- 5: Expert/Can teach

### Step 3: Priority Matrix
| Skill | Current | Target | Gap | Priority | Effort | Timeline |
|-------|---------|--------|-----|----------|--------|----------|
| Kubernetes | 2 | 4 | 2 | High | Medium | 3 months |
| Go | 1 | 3 | 2 | Medium | High | 4 months |
| System Design | 3 | 5 | 2 | High | Medium | Ongoing |

### Step 4: Learning Plan (70-20-10 Rule)
- **70% On-the-job**: Volunteer for relevant projects, shadow experts, own migration
- **20% Social**: Mentorship, tech talks, code reviews, open source
- **10% Formal**: Courses, certs, books, conferences

## Learning Resources by Skill

### Kubernetes
- **Free**: Kubernetes the Hard Way (Kelsey Hightower), CNCF Training
- **Cert**: CKAD → CKA → CKS progression
- **Practice**: Kind, k3d, minikube local clusters

### System Design
- **Books**: "Designing Data-Intensive Applications" (Kleppmann), "System Design Interview" (Alex Xu)
- **Sites**: systemdesignprimer.com, bytebytego.com
- **Practice**: Mock interviews (Pramp, interviewing.io)

### Go/Rust
- **Go**: Tour of Go, Effective Go, Go by Example
- **Rust**: The Rust Book, Rustlings, Zero to Production in Rust

### Leadership
- **Books**: "Staff Engineer" (Will Larson), "An Elegant Puzzle" (Will Larson), "High Output Management" (Grove)
- **Newsletters**: StaffEng, LeadDev, Pragmatic Engineer

## Tracking Progress
- Monthly self-assessment (15 min)
- Quarterly manager sync on growth plan
- Maintain "brag document" / career journal
- Public learning: blog posts, talks, OSS contributions
